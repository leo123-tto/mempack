# 把记忆放在自己的另一台机器上

默认情况下，记忆文件夹在你正在用的这台电脑上（`~/mempack-data/`）。如果你有一台一直开着的机器——家里的小主机、NAS——可以把记忆文件夹放在那里，各台电脑上的 AI 上传时都送到同一个地方。

## 需要什么

- 那台机器能用 `ssh` 免密码登录（你的电脑上执行 `ssh 主机名` 能直接进去）。
- 两边都有 `rsync`（macOS 和绝大多数 Linux 自带）。

## 怎么设

1. 在那台机器上建一个只有你自己能进的文件夹，里面建一个 `inbox`：

   ```
   ssh 主机名 'mkdir -p -m 700 ~/mempack-data/inbox'
   ```

2. 在每一台要上传记忆的电脑上，建配置文件 `~/.config/mempack/config`，写一行：

   ```
   MEMORY_REMOTE=主机名:mempack-data
   ```

   那台机器在家里和在外面要用不同地址连的，可以写两个，空格隔开，按顺序试：

   ```
   MEMORY_REMOTE=家里的地址:mempack-data 外面的地址:mempack-data
   ```

之后说「上传记忆」，脚本会把要交的东西先收到本机一个临时文件夹，送过去，再把本机这份删掉。连不上就什么都不交，也不留副本。

网页版、手机版 AI 导出的文件，下载之后用这一句送进去：

```
bash ~/.agents/skills/mempack/scripts/drop.sh <下载的文件> <是哪个 AI>
```

## 要知道的

- **上传只写不读。** 脚本只往 `inbox/` 里放东西，不列、不取那边已有的任何内容。
- **这仍然是规矩，不是锁。** 你电脑上的 AI 既然能替你 `ssh` 到那台机器，技术上就能看那边的文件。想做成真正「只能交、不能看」，可以在那台机器上给上传单配一把受限的钥匙（`authorized_keys` 里用 `rrsync -wo` 把它限制成只能往 `inbox/` 写）；这一步目前要你自己设，脚本还没有代办。
- **用聊天软件把导出文件转给家里机器上的助手，文件会经过那个聊天软件的服务器。** 这条路方便（手机上导出、转发、说一句「把这个放进记忆收件箱」），但等于多了一个见过这份文件的地方。含客户或别人信息的导出，走电脑上的 `drop.sh` 更稳妥。
- **整理要在够得着那个文件夹的地方做。** 「整理记忆」「生成启动包」需要读写整个记忆文件夹。让那台机器上的 AI 来做，或者你临时把文件夹取回本机、做完再放回去。脚本目前不代办来回搬。

## 临时取回本机整理（放回后必须删掉本机那份）

你在一台够不着记忆文件夹的电脑上、又想让本机的 AI 来整理时，可以临时把整个文件夹取回本机，做完再放回去。做法：

1. 取到一个**专门的工作目录**，不要用系统临时目录（`/tmp`）——系统会自己清它，放回前被清掉就麻烦了。建议 `~/mempack-work/`。取回时排除备份和旧底：
   ```
   rsync -a --exclude '留底-*/' 主机名:mempack-data/ ~/mempack-work/mempack-data/
   ```
2. 在本机这份上做整理。
3. 放回盒子，用 `--checksum` 让两边逐文件对齐，`--delete` 清掉盒子上已删的：
   ```
   rsync -a --delete --checksum --exclude '留底-*/' ~/mempack-work/mempack-data/ 主机名:mempack-data/
   ```
   放回前先在那台机器上备份一份正本（`tar` 到 `~/mempack-backups/pre-overwrite-<时间>.tar.gz`），放回后逐文件比对一遍（两边 `md5` 或 `rsync -n -c` 应为空）。

   **放回前先试放一遍，看你取走之后那台机器上有没有来新东西。** 你在本机整理的这段时间里，那台机器照样在收件：定时取信会往 `inbox/` 放新件、往 `run/` 里写取件日志，别的 AI 也可能刚做完一次「记忆上传」。直接带 `--delete` 放回，这些都会被你手上的旧副本盖掉或删掉——收件箱里新来的一份会凭空消失，取件日志少一行，下次点名就把「交过」报成「没交」。所以：
   ```
   rsync -a -n -i --delete --checksum --exclude '留底-*/' ~/mempack-work/mempack-data/ 主机名:mempack-data/
   ```
   先看它列出的变动：`inbox/` 下要删的，凡是不是你这次已经收进 `originals/` 的，都是新来的；`run/` 下有你没碰过、却要被改回旧样的文件（比如取件日志），说明那边写过。有这两种情况，先把那几份从那台机器取回本机副本（新来的件留在 `inbox/` 等下一轮，日志用那边的），再试放，直到列出的只剩你这次改的东西，才真的放回。
4. **做完立刻删掉本机那份**（`rm -rf ~/mempack-work/mempack-data/`），并在 `run/STATUS.md` 里记一行：取回的时间、做的哪一轮、放回的时间、比对结果、本机副本已删。

这么做的取舍：本机工作期间，记忆全文在这台电脑上，同机别的 AI 技术上读得到；这是为了让本机的 AI 能整理，换来的一次性暴露。整理完马上删，暴露窗口就这一次。

这条和 `SKILL.md` 里「中间草稿只放记忆文件夹的 `run/work/`、不写系统临时目录」不冲突：`run/work/` 管的是**整理过程产生的草稿**，本机的这份是**整个文件夹的一次性副本**。两个都不该留在系统会清理的 `/tmp` 下。
